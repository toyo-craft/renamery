【日本語】

■ ソフトの概要
ReNameryは、クラシックな名作リネームソフトの直感的な操作性をリスペクトし、現代の技術で再構築した高機能・一括ファイル名変更ツールです。
直感的な3ペインレイアウト、リアルタイムプレビュー、連番付与、正規表現による置換などを備え、マルチプラットフォーム環境において横断的に動作します。

■ インストール・アンインストール方法
- インストール方法 (ZIP版): 
  ダウンロードしたZIPファイルを任意のフォルダに解凍し、中にある実行ファイル（ReNamery.exe 等）を起動してください。
  ※ ポータブル版であるため、USBメディア等の外部ストレージに保存（解凍）して持ち運ぶことも可能です。
  ※ インストーラー版（.msi）もGitHubにて併せて公開しています。
- アンインストール方法:
  解凍したフォルダ一式をそのまま削除（ごみ箱へ移動）するだけでアンインストールが完了します。「アプリと機能（プログラムの追加と削除）」の一覧には表示されませんのでご注意ください。

■ セキュリティソフトによる誤検出について（重要）
本ソフトには「起動時にGitHub上の最新バージョンの有無を確認する」というアップデートチェック機能が含まれています。
この外部通信が原因で、一部のアンチウイルスソフトやWindows SmartScreen等においてマルウェア（悪意のあるプログラム）として誤検出される場合があります。本ソフトには悪意のあるプログラムやアフィリエイトツール等は一切含まれておりませんので、ご安心ください。実行をブロックされた場合は、セキュリティソフトの除外設定（許可リスト）に追加してご利用ください。

■ Software Overview
ReNamery is a modern, high-performance batch file renaming utility that inherits the intuitive operability of classic renaming tools, rebuilt with modern technology.
It features a 3-pane layout, real-time preview, advanced numbering, regex text replacement, and seamlessly supports Multi-Platform environments.

  - Android : apk format
  - Linux : tar format, deb format

■ Installation and Uninstallation
- Installation (ZIP version):
  Extract the downloaded ZIP archive to any folder and run the executable file (e.g., ReNamery.exe).
  * As a portable application, it can also be extracted to and run directly from a USB flash drive.
  * We also provide an Installer version (.msi) on our GitHub page.
- Uninstallation:
  Simply delete the extracted folder to completely uninstall the software. You will not find it in the Windows "Programs and Features" or "Apps & features" list.

■ About False-Positive Malware Detection (Important)
This software includes a feature that automatically checks GitHub for the latest version upon startup.
Because of this background external network access, some antivirus software or Windows SmartScreen might incorrectly flag it as malware. Please be assured that this software contains no malicious code, keyloggers, or adware. If the execution is blocked, please manually add the application to your antivirus software's exclusion/exception list.
