# 解決すべき課題リスト

ここに解決したい課題やバグ、要望を箇条書きで記述してください。

私はこのリストの上から順に対応を行い、一つ解決するごとにレビューをお願いします。

- [x] 課題1: 自由入力欄（左右中央ペインすべて/中央ペインはアドレスバー、名前変更）にフォーカスされているときは、アプリのショートカット（Ctrl+A、Ctrl+C、Del等）が解除されるように。そうでないと例えば、テキストを消すためDELを押すとファイル削除に移行してしまう
- [x] 課題2: 中央ペインのファイル名変更時にCtrl+Aを押すと、ショートカットキーが効いてします
- [x] 課題3: 自由入力欄でアプリのショートカットが効かなくなりましたが、本来の機能である文字全選択（Ctrl＋A）、前方文字削除（DEL）も効かなくなったので修正してください
- [x] 課題4: タブレット版のアプリのデザインにおいて、左ペインが折りたたまれたときの、メニュー開閉ボタンが表示されなくなった
- [x] 課題5: MaterialDesign3に可能な限り準拠してください
- [x] 課題6: モバイル版のアプリのデザインにおいて右ペインに関してどの様にあるべきか考慮してほしい
- [x] 課題7: アプリケーション幅が狭い場合、メニューは非表示されない問題を解消のため、足し応報のベストプラクティスを検証して、3パターン提案してください
- [x] 課題8: 左ペインの特殊フォルダを表示した場合、クイックアクセス配下が開くのではなく、実体フォルダがカレントとして開く。例えば、OneDriveをクリックすることで、C:\Users\USERNAME\OneDriveにカレントが移動しますが、OneDrive配下にC:\Users\USERNAME\OneDriveの内容が表示されるべきです
- [ ] 課題9: 検索/置換、拡張子の変更/追加の入力欄を履歴のドロップメニューに対応してください
- [ ] 課題10: タイムスタンプの自由入力欄を、時刻対応したカレンダー入力に対応してください
- [x] 課題11: タブレット版（ランドスケープ）である場合は右ペインは表示してください
