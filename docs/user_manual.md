# ReNamery ユーザーマニュアル

> [!WARNING]
> **ベータ版に関するご注意**
> 本アプリは現在ベータ版です。利用実績がまだ浅いため、予期せぬ不具合が含まれている可能性があります。
> 大切なファイルを扱う際は、事前にバックアップを取るなど、十分に注意してご利用ください。

ReNamery（リネームリー）は、名作リネームソフト「Namery」をリスペクトし、現代の技術（Flutter）で復刻・再構築したファイル名変更ツールです。
Windows / Google Android /Chromebook で動作します。
※強い要望があれば macOS / Linux  / iOS (iPhone/iPad) リリースも検討。

## 主な機能

ReNameryは、画面上部にある「タブ」を切り替えることで、様々なリネーム操作を行うことができます。

### 1. Main（基本）タブ
ファイル名の基本的な変更を行います。

**便利な機能:**
- **ピン留めアイコン (連番の保存)**: 連番入力欄の左あるピンアイコンをONにすると、リネーム実行後に連番のカウントをリセットせず、次回のリネーム時に続きの番号から開始します。連続して別々のファイル群に連番を振りたい場合に便利です。

- **文字列 + 連番**: 指定した文字列の後に連番を付けます。
- **現在名 + 連番**: 現在のファイル名の後に連番を付けます。
- **連番 + 文字列**: 連番の後に指定した文字列を付けます。
- **連番 + 現在名**: 現在のファイル名の前に連番を付けます。
- **置換**: ファイル名の中の特定の文字を、別の文字に置き換えます。
- **挿入**: 指定した位置に文字を挿入します。
- **削除**: 指定した位置の文字を削除します。

### 2. Sub（拡張）タブ
拡張子の変更や、より高度なリネームを行います。

#### 拡張子 (Extension)
- **拡張子を変更**: ファイルの拡張子を指定したものに変更します（例: `txt` → `md`）。
- **拡張子を追加**: ファイル名の末尾に拡張子を追加します（例: `file` → `file.bak`）。
- **拡張子を削除**: 拡張子を削除します。
- **拡張子を大文字化/小文字化**: 拡張子の大文字・小文字を統一します（例: `.JPG` → `.jpg`）。

#### 英単語整形 (Format)
- **単語の先頭を大文字化**: スペース、ハイフン、アンダースコアで区切られた単語の先頭を大文字にします（Proper Case）。
  - 例: `my_document_file.txt` → `My_Document_File.txt`

#### 文字列リネーム (List Rename)
複数のファイルを、テキストリストに基づいて一括でリネームします。
**TSV（タブ区切り）形式**のテキストデータを貼り付けることで、任意のファイル名に変更できます。
Excelなどで作成したデータを活用するのに適しています。

**使い方:**
1.  **テキスト入力モード**を選択します。
2.  下のテキストエリアに、以下の形式で変更ルールを入力します。
    ```text
    変更前のファイル名 [タブ] 変更後のファイル名
    ```
    または、単に変更後のファイル名だけを1行ずつ並べることも可能です（その場合、リストの上から順に適用されます）。

**マッチング（検索）ルール:**
以下の順序でリネーム対象のファイルを特定します。
1.  **完全一致:** リストの「変更前の名前」が、実際のファイル名（拡張子を含む）と完全に一致する場合。
2.  **拡張子なし一致:** 完全一致が見つからない場合、実際のファイル名（拡張子を除く部分）と一致する場合。

**拡張子の扱い:**
- **変更後の名前**に拡張子が含まれている場合、拡張子ごとその名前に変更されます。（例: `old.txt` → `new.doc`）
- **変更後の名前**に拡張子が含まれていない場合、元のファイルの拡張子が維持されます。（例: `old.txt`を `new` に変更 → `new.txt` になる）

**入力例 (タブ区切り):**
```text
old_name.txt	new_name.txt
image01.png	photo01.png
report.doc	final_report.doc
```
※ `[TAB]` はキーボードのTabキーで入力します。Excelなどの表計算ソフトから2列コピーして貼り付けると自動的にこの形式になります。

**便利なサンプル機能:**
ドロップダウンメニューから、よく使うパターンのサンプルを呼び出せます。
- **サンプル: 連番ファイル**: 章立てされた動画ファイルなどの連番リネームの例。
- **サンプル: 拡張子一括置換**: 拡張子をまとめて変更する例。
- **サンプル: 特定文字の置換**: 特定の文字列を一括で置き換える例。

### 3. Extra（高度）タブ
日付の付加や、文字種の変換を行います。
- **ファイルの日付を付加**: 作成日や更新日をファイル名に追加します。フォーマットや位置（先頭/末尾）を自由に指定できます。
- **全角/半角変換**: 英数字、カナの全角・半角変換を行います。

### 4. Attributes（属性）タブ
ファイルの属性やタイムスタンプを変更します。
**注意**: この属性タブによる変更は**元に戻す（Undo）ことができません**。慎重に操作してください。
- **属性を変更**: 読み取り専用、隠しファイルなどの属性を変更します（Windowsのみ）。
- **タイムスタンプを変更**: ファイルの更新日時を任意の日時に変更します。

## その他の便利機能

### フィルタ設定 (左パネル)
フォルダツリーの表示や、処理対象ファイルの絞り込みができます。
- **フォルダアイコン (フォルダの表示/非表示)**: タイトルバーにあるフォルダアイコンをクリックすると、ファイルリスト内でのフォルダ（ディレクトリ）の表示・非表示を切り替えることができます。ファイルのみを対象にしたい場合に非表示にすると見やすくなります。
- **システムファイルを非表示**: OSのシステムファイルをリストに表示しません。
- **下位フォルダ検索（再帰検索）**: 選択したフォルダの中にある、サブフォルダ内のファイルも含めてリストアップします。大量のファイルを一括処理する場合に便利です。
- **プレビュー表示**: 画像ファイルなどを選択した際、右下にプレビューを表示します。

### ドラッグ＆ドロップ
エクスプローラー（Finder）からReNameryのファイルリストへファイルやフォルダをドラッグ＆ドロップすると、その場所をすぐに開くことができます。

### Undo（元に戻す）
リネーム実行後、ツールバーの「戻す」ボタン（または `Ctrl+Z`）を押すことで、直前のリネーム操作を取り消して元の名前に戻すことができます。
※ 属性変更やタイムスタンプ変更は対象外です。

### マクロ機能について
Nameryにあったマクロ機能は現在実装されていませんが、強いご要望があれば実装を検討いたします。
