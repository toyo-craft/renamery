Namery：3ペイン構成とリネーム機能の全貌

Nameryのインターフェースは、視線の移動を最小限に抑え、操作の認知負荷を下げるために設計された「3ペイン構成」を採用しています[1][2]。各ペインの役割は以下の通りです。

**1. 左ペイン：ナビゲーションと探索 (Navigational and Preview Infrastructure)**このペインは、対象となるファイルやフォルダへのアクセスを担います[3]。

• **フォルダツリー**: エクスプローラー風の階層表示により、ユーザーはディレクトリを素早く移動できます[3][2]。

• **下位フォルダ検索**: 親フォルダだけでなく、その中のサブフォルダに含まれるファイルも処理対象とするための設定（チェックボックス等）が可能です[4]。

• **ファイルプレビュー**: ツリービューの下部にはプレビューウィンドウがあり、画像ファイルなどを選択した際にその内容を視覚的に確認できます[3][2]。

**2. 中央ペイン：リスト表示とリアルタイムプレビュー (Central Pane / Real-time Preview Engine)**このペインはアプリケーションの核となる作業領域であり、WYSIWYG（見たままが得られる）を実現する安全装置としての役割も果たします[5]。

• **変更前後の対比**: 「現在のファイル名」と、設定適用後の「変更後のファイル名」を並列でカラム表示します[3]。

• **リアルタイムプレビュー**: ユーザーがルールを変更すると即座にこのリストが更新され、実行ボタンを押す前に結果を目視で確認できます[3][2]。

• **順序の制御**: 連番（ナンバリング）処理を行う際、ファイルに番号が振られる順序を決定するために、ツールバーの矢印ボタンを使って手動でファイルの並び順を入れ替える操作もここで行います[3][6]。

**3. 右ペイン：ルール設定パネル (Rule Panel / Logic Configuration)**このペインはリネーム処理の「ロジック」を構築するエンジンの役割を果たします[5]。機能の複雑化を防ぐため、以下の4つのタブに分割されています[5][7]。

• **Mainタブ**: 文字列の置換、挿入、連番付与などの基本操作[8][7]。

• **Subタブ**: 拡張子の変更や削除、外部リストの取り込み[9][6]。

• **Extraタブ**: 日時の付与や、全角・半角変換などの文字種操作[10][11]。

• **etcタブ**: 属性変更（読み取り専用など）やタイムスタンプの変更[12][11]。

このようにNameryは、左で「素材を選び」、右で「加工ルールを決め」、中央で「結果を確認する」という一連の流れを単一ウィンドウ内で完結させる設計となっています[1][2]。
