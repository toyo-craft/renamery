# ReNameryとは
ReNameryプロジェクトは、開発が実質的に停止しているファイルリネームツール「Namery」のユーザーエクスペリエンス（UX）に触発され、これをFlutterフレームワークを用いて現代に復活させることを目的としています。
このプロジェクトは、Nameryの持つ以下の主要な特徴や利点を引き継ぎ、Flutterの技術で再構築することを目指します。
 * 使いやすいインターフェース: Nameryが評価されていた直感的で分かりやすいUIを、Flutterのモダンなデザイン原則に基づいて実現します。
 * リアルタイムプレビュー: リネーム後のファイル名を即座に確認できるリアルタイム変換処理を核とし、ユーザーが安心して操作できる環境を提供します。
 * 高機能なリネーム: 下位層を含むファイルやフォルダの一括変更、マクロによる複雑なリネーム処理、連番や特定文字列の追加といった、Nameryが備えていた多機能性を再現します。
 * アンドゥ機能: 変更の取り消しが可能なアンドゥ機能を実装し、試行錯誤しながらリネームを行える柔軟性を提供します。
Flutterは、単一のコードベースからiOS、Android、Web、デスクトップアプリケーションを構築できるクロスプラットフォームフレームワークであり、ReNameryプロジェクトはこの技術を活用して、より幅広い環境での利用を可能にすることを目指します。これにより、以前のNameryユーザーはもちろん、新たなユーザーにも、効率的で快適なファイルリネーム体験を提供することが期待されます。

# Nameryとは
Nameryは、Windows XP上で動作するフリーの高機能ファイルリネームツール（リネーマー）です。
主な機能と特徴
 * リアルタイムプレビュー リネーム後のファイル名がリアルタイムで表示されるため、変換結果を事前に確認できます。
 * 一括変更 下位層を含むファイル名やフォルダ名、拡張子の一括変更が可能です。
 * 操作性 使いやすいインターフェースを持ち、説明書を読まずとも直感的に操作できると評されています。
 * 多彩なリネーム設定 マクロによる複雑なリネームや、連番、指定文字列の追加、大文字化・小文字化などの設定が可能です。
 * アンドゥ機能 変換を間違えた場合でも、何度でもやり直しができる「アンドゥ」機能を備えています。
 * プレビュー表示 Susie-Pluginを利用した画像のプレビュー表示機能も搭載しています。
 * その他 エクスプローラとの関連付け機能、クリップボードへのファイル名一覧コピー機能、固定リストや履歴リストの利用、インストール不要で実行可能などの特徴があります。
主に、デジカメ写真や動画ファイルなど、多数のファイルの管理を効率化するために利用されます。

# Nameryの仕様について
@namery_manuals
NameryのヘルプがHTML形式で格納されています。これをベースに設計書を作成していきます。

@namery_docs
Nameryのヘルプや、ネットにある情報から概要を整理したドキュメントです。
しかし誤りの可能性があるため、あくまで@namery_manualsが主、@namery_docsは従の関係にあります。
